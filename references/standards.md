# 验收标准（用户逐版返工确认过的硬规则，v1→v11 沉淀）

## 1. 内容完整性
- 只丢核实过的重录 / 口误 / 纯空白；**不许为时长删内容**。丢弃前先在转写里看到「后一句是前一句的延长」或用户点名。
- 手工丢弃范围按**静音谱区间中点**判定（`edl_rules.MANUAL_KILL`），不按 ASR 段——段比区间宽，会误伤相邻好句。
- whisper 会把同一句幻觉成 2–3 遍、自动前缀法只留到句尾 → 用 `MANUAL_KEEP` 强制保留真句。
- 母版重剪后**必须重做人物层**（main_v / pip / main）并跑 `preflight.py`；三层时长与母版差 >0.1s 不许渲染。
- 片尾「请不吝点赞订阅…」是 whisper 幻觉，整条丢。

## 2. 气口
- `silencedetect -27dB:0.16`；PAD 0.10；普通换气上限 0.22s；段落停顿 0.40s（语速快用 0.16 / 0.30）。
- `aselect` 不剪音频——必须 `trim/atrim + concat`。

## 3. 素材
- iPhone 前置素材：rotation 元数据 + **水平镜像**（海报/衣服文字反向）→ `HFLIP=True`。每个项目在 plan 阶段抽帧让用户确认。
- 720p 源按 1080p 出片：图形与截图原生清晰，人物层是 lanczos 放大；要真 1080p 得重录，交付时说明。
- 音轨：成片用母版音轨 **stream copy** 换回（Remotion 重编码 AAC 会带 42.7ms 偏移）；MD5 必须一致。

## 4. 字幕
- 居中描边白字 54px，关键词金色 + 金线从左向右描出 0.33s；一行 ≤16 字，词语保护表不许拦腰断词；无过短 / 重叠。
- 只改 ASR 错字（`cue_rules.FIX`），字幕跟实拍走；跨 ASR 段的词拆成两条替换。

## 5. 画面结构
- 人物三态只允许：全屏 / **左下圆窗**（大圆 360，接管板小圆 230）/ 全隐。**圆窗永远左下角**。全屏 ↔ 圆窗用**两层淡入淡出**（全屏层淡出、圆窗淡入 + 0.94→1 轻微缩放）；试过同层连续收束（v10），用户明确不要。
- 大图（截图 / 长图）出现时人物必须缩成左下圆窗，图居中偏右 1000–1060px，**任何浮层不得压脸**。
- 脑图板 ≤8 块、屏上时长 ≤55%、节点 ≤7、板与板之间回人物全屏、最长纯人物段 ≥20s；开头钩子与结尾 CTA 纯人物。
- 开场解释段（如「FDE 是什么」）用**小圆框 + 脑图板**，不用全屏人物 + 词条（用户 v7 反馈：不如小圆框）。
- 章节标签贯穿全片首尾相接；左上文字 ≥34px（词条）/ 40px（标签）。
- 顶部有箭头链时脑图树右移（`BOX={板号:{"x0":720}}`）；大图在右侧时链改**竖排流程卡**（`dir:"v"`）——横排会撞图。
- 大字数据顶部 130（标签下方），不与标签重叠。

## 6. 动效纪律
- 贴纸 / 词条 / 链格统一**提前 0.3s**（LEAD）落在说到那个词的瞬间；入场 0.25–0.35s（弹性 0.82→1 + 白闪 3–7 帧落位），出场 ≤0.2s；截图、接管页落定后**完全静止**，禁止漂移。
- 组间隔 ≥1.4s：各自贴边淡出 / 淡入，人物回全屏；<1.4s：以边界中点为中心交叉溶解（否则硬切或人物闪回）。
- 相接的板 + 大图合并成「隐人区块」算人物包络；同形态圆窗连续段合并，避免边界处透明度掉到 0.5。
- SVG 连线渐变必须 `userSpaceOnUse`（垂直连线包围盒宽 0，默认模式整条不渲染）；结论卡连线从紧邻上一行汇聚，不跨层穿卡。
- 行距按每行最高卡片自适应（图片卡比文字卡高 3–4 倍）；缩放上限 1.35。
- 徽章（? ! ✓）慎用，用户反馈「?」显得 AI；✓ 只放在流程链末尾。
- 边框一律药丸 / 大导角：贴纸 999、节点 20、主卡 26、图框 22。
- 脑图节点列表**按台词时序排**（reveal 单调递增，乱序会把早说的节点推迟）；**结论节点不许带子节点**——rawLayout 不递归 concl 子树，挂上去的子节点会静默消失（gen_spec 已加校验）；接管板允许缺 b1/b2/f1-f3（缺=不渲染）。
- 图形段背景 = **暗色磨砂玻璃**：房间画面缩到 160px → gblur σ16 → 放大 → 压暗（brightness −0.30 / saturation 0.4 / contrast 0.82）→ 胶片颗粒 `noise=alls=18`，预渲染成 `bg.mp4`；Remotion 里再叠 rgba(8,9,12,0.52) 玻璃 tint + 5% 斜向反光 + 暗角 0.55。**要求：人形轮廓完全化开、不能比 v8 亮、不用点阵。** CSS blur 渲染极慢，不许用。

- **视频展示**：`show_video(src,w,ar,cap,a,b,full,pip)` —— full=True 全屏 B-roll（开场铺底，pip="none" 时人物全隐）；否则右侧视频卡。**卡内视频必须包 Sequence(from=卡出现帧)**，否则从合成 t0 播、出现时已是冻结末帧。素材预先用 ffmpeg setpts 变速到窗口长度。stat 与全屏视频不参与展示层防重叠平移。

## 7. QA 清单（`render.py` 自动跑）
解码无错 · 帧数 = 时长×30 · 音轨 MD5 = 母版 · 黑帧 0 · 白闪 0 · **真重复帧 0（freezedetect n=0.0001）**——n=0.001 会把「页面刻意静止 + 圆窗里人在动」误报 · contact sheet 亲眼看：卡片 / 字幕 / 圆窗 / 大图无碰撞。

## 8. 交付
每版独立版本号不覆盖；MP4 + SRT + QC contact sheet 拷到 `~/Downloads/<项目>_<版本>/`；中文汇报：时长、丢弃摘要、文案出入、QA 数字、未改动项。

- **剪映二剪注意**（交付时主动告知用户）：成片是 1080p，剪映里**导出分辨率必须选 1080P**、码率「较高」或 ≥20Mbps、关掉超清增强/智能补帧；选 2K/4K 导出 = 把 1080 整体上采样 1.33×，字幕卡片全变软毛边（2026-09 实测）。剪映只加片头贴纸这类小改动时，优先把改动拿回 Remotion 原生渲，避免代际重编码。

## 9. 环境坑
- ffmpeg 必须带 libx264。**Anaconda / conda 自带的 ffmpeg 没有 libx264**——`tools.py` 自动跳过它挑下一个，也可 `export FFMPEG=…` 指定。本流水线不依赖 libass / drawtext（字幕由 Remotion 画）。
- Remotion：浏览器默认用它自动下载的 chrome-headless-shell，下载失败（常见于国内网络）时 `export REMOTION_BROWSER_EXECUTABLE=<本机 Chrome>`；public/ 有大视频必须先 `remotion bundle` 再渲；`--concurrency=1 --offthreadvideo-cache-size-in-bytes=536870912`；**渲染进程没退出会再起 ffmpeg 覆写产物**，换轨前等它退出（`render.py` 已处理）。
- **Node 26 + Remotion 4.0.410**：自带的浏览器解压（extract-zip）静默中断，17 个文件只解出 2 个 → 渲染报 `No browser found for rendering frames`（Node 22 正常）。`preflight.py` 会检测并用 Python 补解，所以 stills / 整片渲染前都先跑 preflight。
- 中文字体走系统字体栈（macOS 冬青黑体 / Linux Noto Sans CJK / Windows 微软雅黑），仓库不分发字体文件；Linux 没装中文字体会出方块。
- 渲染前磁盘 ≥ 6GB（帧暂存 ~2.5GB）。
- **并发默认 1**。并发 2 在内存吃紧（swap 见底）时会随机产出「整幅画面 3×3 瓦片拼贴」的乱帧，位置不固定、复现不稳定；`spike_scan.py` 扫到单帧突变就整片重渲。要提速先关别的应用，再 `CONCURRENCY=2 ./render.sh`。
- 视频层上**禁用 CSS filter**（brightness/blur 等）：会触发同一瓦片缺陷且极慢；压暗用黑色叠层，磨砂用预渲染 bg.mp4。
- **hook 数量必须恒定**：`useCurrentFrame` 等 hook 不许写在条件渲染后的 `.map()` 里——每个动效项抽成独立子组件、hook 无条件顶部调用，条件挂载交给父级。违者 React #310 只在整片/序列渲染时炸，`remotion still` 单帧预览测不出。
- `--sequence` PNG 序列命名：整片渲染补零（element-0000.png）、`--frames=a-b` 不补零（element-1770.png），混用前先统一，否则 ffmpeg `%d` 找不到文件。
- **`--sequence` 全不透明帧会写成 RGB（PNG colortype 2），透明帧是 RGBA**：混格式序列喂 ffmpeg overlay，每次格式切换滤镜图重建、把主输入积压帧一起冲掉——非确定性丢 3–13 帧、只在长流水出现，短窗口测试测不出，`-v error` 无任何告警。合成前必须把整个序列归一成 RGBA（PIL convert，ProcessPool 要用实体 .py 文件，macOS spawn 下 heredoc 子进程会静默崩）；合成后必查 packet 连续性：`ffprobe -show_entries packet=pts_time` 找 >40ms 缺口，帧数必须等于母版。
- **给外来成片叠动效前，先 1fps 扫全片找烧录图形**（`fps=1,scale=256:144,tile=12x8` 拼 contact sheet 亲眼看）：别人剪的片子里 B-roll/面板可能散布全片，稀疏抽帧会漏，叠上去就是撞车。
